# FurmX 低代码平台 — 开发总结

> 2026年7月31日 - 8月1日

---

## 1. 代码结构清理

**问题**：`apps/designer`、`apps/renderer`、`apps/admin` 三个独立应用与 `apps/web/src/views/` 中同名文件夹功能重复，且无任何交叉引用。

**处理**：删除三个独立应用，`apps/` 下只保留 `server` 和 `web`。前端统一入口为 `apps/web`，路由全部指向 `views/`。

---

## 2. 登录/注册页重构

**问题**：旧版居中白色小卡片 + 灰色背景，视觉简陋。

**方案**：左右分栏布局，左侧品牌区（Logo、产品名、特性列表、装饰圆），右侧表单区（标题、输入框、按钮），淡灰+白配色，无渐变。注册页复用相同布局。

**文件**：`apps/web/src/views/auth/LoginView.vue`、`RegisterView.vue`

---

## 3. 表格操作按钮统一

**问题**：表格"操作"列按钮风格不统一，有的用 `text` 文字按钮，有的用 `size="small"` 实心按钮。

**方案**：统一为 `el-button size="small"`，与流程管理页保持一致。

**涉及文件**：`FormListView.vue`、`DataListView.vue`、`MemberManage.vue`、`RoleManage.vue`、`NotificationListView.vue`、`HomeView.vue`

---

## 4. 页面标题层级统一

**问题**：页面标题混用 `<h2>` 和 `<h3>`，底部间距不统一。

**方案**：全部统一为 `<h2>` + `margin: 0 0 16px`。

---

## 5. 布局背景统一

**问题**：`RenderLayout` 背景 `#f5f7fa`，`DefaultLayout` 和 `BlankLayout` 背景 `#f0f2f5`，不一致。

**方案**：统一为 `#f0f2f5`，并改用 CSS 变量 `var(--app-bg-page)`。

---

## 6. 暗色模式

**问题**：无暗色模式。

**方案**：
- `stores/app.ts` 新增 `isDark` + `toggleDark()`，watch 自动同步 `html.dark` 类 + localStorage 持久化
- `theme.css` 新增 `html.dark { ... }` 覆盖 CSS 变量和关键选择器
- `DefaultLayout.vue` 侧边栏底部加圆形切换按钮（☀/🌙）
- 各页面关键硬编码色值覆盖

**不需要 width 约束**：用户反对 `max-width: 1200px`，已全部移除。

---

## 7. 403/404 错误页重构

**问题**：旧版 403 页用了紫色渐变背景（`theme.css` 中 `.blank-layout` 的 `linear-gradient`）。

**方案**：移除渐变紫，改为 `var(--app-bg-page)` 纯色背景。错误页卡片式居中，大号状态码 + 说明 + 返回按钮。

---

## 8. 新用户注册 403 问题

**问题**：新用户注册后无工作空间，调用任何工作空间接口都 403。

**原因**：注册只创建用户，未创建工作空间和成员关系。

**修复**：
- 后端 `AuthService.register()` 和 `login()` 调用 `ensureWorkspace()` 自动创建默认空间
- 后端 `WorkspaceService.list()` 返回空时自动创建（权威兜底）

---

## 9. 通知系统优化

**问题**：未读消息无红点标识；"全部已读"按钮清空了消息列表；无清理功能；无滚动。

**方案**：
- `NotificationBell.vue`：未读项加红点，全部已读只标记不删除，弹窗限高 400px 滚动
- `NotificationListView.vue`：未读行加红点列，新增全部已读/清除所有按钮，表格自适应高度
- 后端新增 `DELETE /notifications/clear-all`

---

## 10. 流程引擎 — 表达式求值 Bug 修复

**问题**：条件分支中 `amount <= 5000` 永远不匹配，`>=`、`<=`、`!=` 全部失败，只有 `>`、`<`、`==`、`&&`、`||` 能用。

**根因**：`expression-eval.ts` 中 `peek(offset = 0)` 默认 offset 写成了 0，导致 `peek()` 返回当前字符而非下一个。`<=` 被拆成 `<` + `==` 两个 token，解析失败。`&&`/`||` 凑巧能用因为前后字符相同。

**修复**：`offset = 0` → `offset = 1`，一行改动修复所有双字符操作符。

---

## 11. SLA 超时升级 + 预警

**问题**：审批节点配置了超时时限和超时升级人，但没有任何运行时逻辑。

**方案**（纯 Node.js 实现，零外部依赖）：
- `sla.service.ts`：内存 `Map<taskId, setTimeout>` 管理定时器
- 任务创建时 `register()` 注册超时升级 + 提前预警两个定时器
- 审批通过时 `cancel()` 清除
- 服务重启 `onModuleInit()` 扫描所有 pending 任务恢复定时器
- 预警：超时前 N 小时通知审批人；升级：超时后自动转交 escalateTo

---

## 12. 抄送节点完善

**问题**：抄送人需要手动输入用户 ID，通知未实际发送。

**方案**：
- 设计器改为多选下拉（从工作空间成员选）
- 引擎 `collectCCRecipients()` 从穿越的 CC 节点提取通知目标
- `startProcess`/`approveTask` 后自动发送抄送通知

---

## 13. 加签/转交改进

**问题**：加签按钮未显示；转交/加签输入框需手动输入用户 ID。

**方案**：
- 待办列表加签按钮：`v-if="canAddSign(row)"` 检查节点 `allowAddSign` 配置
- 转交/加签对话框改为远程搜索下拉（`GET /auth/users?search=`）
- 设计器默认 `allowTransfer = false`，需主动开启
- 后端 `transferTask` 校验 `allowTransfer`

---

**问题汇总**：

## 15. 表单设置页修复

**问题**：提交上限保存无效。

**原因**：前端把 `maxSubmissions` 嵌套在 `settings` 对象里发送，但 `Form` 表中 `max_submissions` 是独立列。

**修复**：前端平铺发送，后端 DTO 接收。删除了未实现的"验证码"和"提交后跳转"选项。

---

## 16. 自动处理节点实现

**问题**：自动处理节点只穿越不执行，三个动作类型都是占位。

**实现**：
- 引擎 `collectAutoTaskActions()` 从穿越的网关提取动作
- 服务端 `processAutoTaskActions()` 统一执行：notify（发通知）、webhook（调接口）、update（更新数据）
- 设计器配置改为结构化表单（非 JSON 文本框）

---

## 17. 撤回逻辑打通

**问题**：画布设置"不允许撤回"不生效。

**修复**：
- 后端 `withdrawProcess` 增加 `settings.allowWithdraw === false` 校验
- `getMyInstances`/`getMyTasks` 查询补 `settings: true`
- 前端"撤回"按钮 `v-if` 增加 `settings.allowWithdraw !== false` 判断

---

## 18. 表单提交页优化

**问题**：提交页样式与设计预览不一致；退出按钮会踢掉工作台登录态。

**方案**：
- 表单页独立登录态（`form_access_token` 隔离），切换账号不影响工作台
- 登录弹窗美化（图标输入框 + 底部链接切换）
- 卡片样式与预览面板完全一致：`gap: 12px 16px`、`padding: 24px`、`border-radius: 4px`、动态宽度 `canvasCols × (800/24)`
- 登录/注册按钮用 `el-button-group` 紧凑排列

---

## 19. 暗色模式表格增强

**问题**：暗色模式下表格边框、表头、分页显示不佳。

**修复**：`theme.css` 中 `html.dark` 增加表格完整变量覆盖（border-color、header-bg、striped-row、hover、pagination）。
