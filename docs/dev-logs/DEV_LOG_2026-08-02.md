## 2. 权限系统

- owner 角色显示名「管理员」→「创建者」
- 新成员默认角色从 editor 改为 viewer
- 创建空间时自动建系统角色（创建者/查看者）
- 禁止创建第二个全权限角色（`permissions` 含 `*` 或全选 30 项均被拦截）
- 创建者禁止降级/被他人修改角色
- 修复权限守卫只查方法级 `@RequiredPermission`，改为同时查类级
- 修复权限缓存不失效 → `syncRbacRole` + `normalizeMemberRoles` 后清缓存
- 修复跨空间权限泄漏（guard 查询加 `role: { workspaceId }` 过滤）
- 修复 `resolveWorkspaceId` 优先取 `formId` 参数（`GET /forms/:formId/submissions/:id` 中 `:id` 是提交记录 ID）
- 移除「提交表单数据」「发起/撤回/删除我的流程」权限选项
- 工作台概览仅需登录，数据分析页面才需 `analytics:view`

## 3. 403 弹窗优化
