## 1. 登录认证修复

**问题：** `pnpm dev` 直接进工作台，没有跳登录页。
**原因：** `tryAutoLogin()` 定义了但从未调用，localStorage 有旧 token 但未验证有效性。
**修复：** `main.ts` 改为 async `bootstrap()`，挂载前 `await authStore.tryAutoLogin()`，token 无效则自动清除跳登录。

## 3. 流程引擎（Phase 2 核心）

| 层级 | 文件 | 内容 |
|------|------|------|
| SDK | `types/workflow.ts` | ProcessDefinition/Instance/Task 类型、状态枚举、转换映射 |

## 4. 五级权限体系

| 级别 | 实现 |
|------|------|
| L1 平台级 | JWT 中首位用户自动 `role:super_admin`，PermissionGuard 放行 |
| L2 工作空间级 | `WorkspaceGuard` 校验成员归属 |
| L3 表单级 | `@RequiredPermission` 装饰器 + `PermissionGuard`（RBAC） |
| L4 行级 | `RowLevelInterceptor` + `buildRowLevelWhere` SQL 条件注入 |
| L5 字段级 | `FieldACLInterceptor` + RendererEngine.filterByACL（双重保障） |

- `PermissionGuard` 无 `wsId` 时自动从资源反查（如 formId → workspaceId）
- 权限矩阵 API: `GET /workspaces/:wsId/roles/matrix`
- RoleManage.vue 升级为矩阵表格 + 分组权限点选择

## 5. SDK 构建修复

**问题1：** `workflow.ts:163` 语法错误 `REJECTED: string`。
**修复：** 去掉多余的 `: string`。

**问题2：** NestJS 报 `No "exports" main defined`。
**原因：** SDK `package.json` 只有 `"import"` 没有 `"require"` 导出。
**修复：** 添加 `"require": "./dist/index.js"`。

**问题3：** `ERR_UNSUPPORTED_DIR_IMPORT`，ESM 模式不支持目录导入。
**原因：** 编译后 `export * from './types'` 无 `.js` 后缀，Node ESM 不认。
**修复：** 全部相对导入加 `.js` 后缀（`'./types'` → `'./types/index.js'`）。
涉及文件：`index.ts`、`engine/index.ts`、`types/index.ts`、`utils/index.ts`、`registry/index.ts`、所有 engine 文件。

## 7. 三端渲染统一

**问题：** 画布、预览、公开表单效果不一致。

**方案：** 创建共享组件和全局 CSS：
- `FieldControl.vue` — 所有控件类型的渲染逻辑（input/textarea/select/radio/checkbox/date-picker/switch/rate/slider 等），PreviewPanel 和 PublicFormView 共用
- `field-shared.css` — 外层/内层容器、标签位置、尺寸变体、控件宽度等样式统一
- CanvasField 也使用 FieldControl，通过 `.field-placeholder` 包裹实现半透明+禁止交互

**关键修复：** 全局 CSS 不能用 `:deep()`（Vue scoped 特性），改为直接后代选择器
