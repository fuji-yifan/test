# 开发总结 2026-08-01（第二轮）

## 提交人与用户信息

- 提交数据/流程/审计日志中所有用户标识统一改为昵称 + hover 显示用户 ID
- 修复 axios 拦截器覆盖表单页 `form_access_token` 导致提交人错认为管理员
- 注册昵称改为必填、可重复

## 个人信息页

- 新建 `ProfileView.vue`，显示昵称/邮箱/状态/登录时间/注册时间
- 支持编辑昵称、修改密码、上传头像（MinIO）
- 删除了标签位置选项，统一左侧

## 审计日志系统

- Prisma 中间件全局捕获 12 类模型的 CUD 操作
- 操作类型级联筛选：表单/数据/模板/流程/任务/成员/角色/其他
- 特定操作名区分：新建表单、发布表单、归档表单、复制表单、提交表单数据等
- 流程操作：通过审批/驳回审批/转交审批/超时升级
- 修复 `updateMany` 导致审批操作不审计
- 修复 `startProcess` 穿越网关后不判断 `finished` 导致流程卡死
- 403 改弹窗提示而非跳转页面

## 角色权限系统

- 重组 8 分组 29 权限点，与审计日志对齐
- 新建角色对话框支持分组全选/取消
- 权限守卫覆盖所有模块（工作流/成员/审计/模板/分析/上传）
